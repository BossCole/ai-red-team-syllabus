# AI Red-Teaming Syllabus

**From Local Setup to Job-Ready · ~24–40 Weeks (a map, not a schedule)**

An interactive, hands-on HTML syllabus for learning AI red-teaming and LLM security. Build a local LLM lab, attack it using the OWASP Top 10 for LLMs framework, automate your own testing workflow with Python tools you build yourself, and assemble a job-ready portfolio.

## What this teaches

- Building and running a local LLM + Docker lab from scratch
- Attacking models using the OWASP Top 10 for LLMs framework
- Using red-teaming tools (Garak, PyRIT, Promptfoo)
- Writing Python and building automation tools — attack harness, RAG tester, scheduled re-scanner
- Assembling a portfolio that leads with the tools you built and automated

## Course structure

| Phase | Title            | Focus                          | Weeks     |
|-------|------------------|--------------------------------|-----------|
| 1     | Foundations      | Local LLM lab + scripting      | 1–4       |
| 2     | OWASP Core       | Attack the LLM                 | 5–10      |
| 3     | RAG + Agents     | Threat model & secure          | 11–16     |
| 4     | Detect & Govern  | Observability & assurance      | 17–20     |
| 5     | Polish & Apply   | Launch your portfolio          | 21–24     |

## How to use

Open **`ai-red-teaming-syllabus.html`** in any modern browser. Progress is saved locally in your browser (per device). No installs or accounts required to take the course.

## Hosting

To share a live link (GitHub Pages), deploy the `ai-red-teaming-syllabus.html` file as a static site at the repository root — the page works standalone.
